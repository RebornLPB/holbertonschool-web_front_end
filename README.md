# Holberton School - Web Front-End

## 📖 About
This repository gathers the projects completed during the **Web Front-End** track at **Holberton School**. It follows the construction of **Techium**, a fictional digital-agency website: first its HTML structure and styleguide, then its CSS design system, grid and components.

---

## 🛠️ General Requirements & Environment
* **Languages:** HTML5 and CSS3 (no JavaScript, no framework).
* **Browser:** Any modern browser (pages are static files).
* **Files:** All files end with a new line.

---

## 📚 Project Overview

| Directory | Core Concepts / Highlights | Key Files |
| :--- | :--- | :--- |
| [`html_advanced`](html_advanced/) | Document skeleton, semantic landmarks, headings, lists, links, images, table, `details`, `video`, `audio`, `iframe` | `index.html`, `styleguide.html`, `36-index.html` |
| [`CSS_advanced`](CSS_advanced/) | Custom properties, typography, normalize, box-sizing, float grid, dark theme, components, transitions | `styles/32-style.css`, `index.html` |

---

## 🚀 Quick Start

```bash
git clone https://github.com/RebornLPB/holbertonschool-web_front_end.git
cd holbertonschool-web_front_end

# Open a page in the browser
xdg-open html_advanced/index.html
xdg-open CSS_advanced/index.html
```
